# Java Mini Projects

A collection of 4 console-based games written in Java, built to practise core programming concepts.

## Games

| Game | Description |
|------|-------------|
| **Guess the Number** | Guess the secret number with 3 difficulty levels, limited attempts, hints and a best-score tracker. |
| **Rock Paper Scissors** | Play against the computer with a live scoreboard and an overall winner. |
| **Tic Tac Toe** | Two-player game with win and draw detection and a scoreboard. |
| **Connect Four** | Two-player game on a 6x7 grid. Get 4 in a row to win. |

## Concepts Used
- Loops (`for`, `while`, `do-while`)
- Conditional statements (`if-else`, `switch`)
- Arrays and 2D arrays
- Methods
- Exception handling (`try-catch`)
- `Scanner` for input and `Random` for random numbers
